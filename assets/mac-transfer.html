Deskflow 文件与剪贴板

Windows ↔ Mac · 同一个局域网，无需额外安装

1 从 Windows 下载

Windows 控制台拖入的文件会出现在这里，点击即可下载到 Mac。

2 发送文件到 Windows

文件会保存到 Windows 的“下载\Deskflow Companion”。

把文件拖到这里或点击选择文件，可一次选择多个
等待选择文件

3 剪贴板互通 手动桥接

Deskflow 正常时会自动同步复制粘贴；这里作为备用通道，文字也可以直接在两台电脑间传递。

连接仅使用同一个局域网 · 访问地址包含随机配对码，请不要公开分享
