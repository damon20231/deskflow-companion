# Deskflow 增强控制台使用说明

适用环境：Windows 主机 `Z790UD` + Mac `MacBook`。
当前版本：v1.1（2026-10-28 修订）
程序：`dist\Deskflow增强控制台.exe`

## 1. 默认页面只有三件事

打开后会看到三个编号大卡片，按 1 → 2 → 3 使用即可：

1. **键鼠连接**：确认 Deskflow 是否正常。
2. **显示器**：选择共享显示器，并一键切到 Windows 或 Mac。
3. **文件与剪贴板**：拖入文件、复制 Mac 访问地址，并打开双向文件和文字剪贴板页面。

右上角有“高级设置”。日常使用不需要打开，DDC/CI、自动切换、诊断和剪贴板测试都收在里面。

## 2. 当前显示器和输入

| 显示器 | 信号 | 用途 |
|---|---|---|
| 左侧 `S2722QC / DISPLAY1` | HDMI 1，`0x11` | Windows |
| 右侧 `S2722QC / DISPLAY5` | HDMI 2，`0x12` | Mac，同时作为共享显示器 |

当前是**手动固定模式**：

- 不自动换源；
- 点击“切到 Mac”，右侧共享显示器使用 HDMI 2；
- 点击“切到 Windows”，右侧共享显示器使用 HDMI 1；
- 左侧 Windows 显示器保持不变。

如果以后换了显示器或设备标识变化，点击“选择共享显示器”，选中实际同时连接 Windows 和 Mac 的那一台。

## 3. 键鼠共享

主页面显示“键鼠连接正常”时即可使用：

- Windows 键鼠跨到 Mac 后，由 Deskflow 继续控制 Mac；
- 从 Mac 跨回 Windows 后，键鼠回到 Windows；
- Mac 只需要安装 Deskflow Client，不需要安装增强控制台。

如果显示“键鼠连接未就绪”，点击“检查键鼠连接”，按提示打开 Deskflow。

## 4. 切换显示器

在“显示器”卡片中：

- **切到 Windows**：共享显示器切换到 Windows 输入；
- **切到 Mac**：共享显示器切换到 Mac 输入；
- **选择共享显示器**：更换要控制的显示器。

显示器换源通常需要 1–3 秒，这是显示器硬件重新同步画面，不是软件卡顿。

Windows 息屏、锁屏或睡眠恢复后，控制台会自动重新扫描共享显示器；切换按钮和读取当前输入时也会刷新显示器连接。若共享屏完全断电，先移动鼠标或按键盘唤醒，再执行切换。

## 5. 文件传输

两台电脑需要连接同一个可信局域网，并保持 Windows 控制台运行。Mac 不需要安装额外的文件传输程序。

### Windows → Mac

1. 把文件或文件夹拖到第 3 区，或点击 **添加文件**；
2. 点击 **复制 Mac 地址**；
3. 在 Mac 的 Safari 或 Chrome 中打开这个地址；
4. 在“从 Windows 下载”中点击对应文件。

共享文件夹时，控制台会把文件夹中的文件逐个列出供 Mac 下载。共享列表只保存在本次运行中，重新启动控制台后需要重新添加。

### Mac → Windows

1. 在 Mac 浏览器打开同一地址；
2. 在“发送文件到 Windows”区域拖入或选择文件；
3. Windows 会把文件保存到：

```text
%USERPROFILE%\Downloads\Deskflow Companion
```

4. 在控制台点击 **打开接收文件夹** 即可查看。

浏览器上传支持多文件。同名文件会自动改名，不会覆盖已有文件。

### 访问地址

- 地址形如 `http://Windows局域网IP:端口/随机令牌/`；
- 地址中包含随机令牌，不要发给不信任的人；
- Windows 首次运行时如果出现防火墙提示，请只允许“专用网络”；
- 服务默认使用 `45873`，被占用时会自动尝试后面的端口；
- 传输页没有 HTTPS，仅限可信局域网使用。

## 6. 复制粘贴

“剪贴板同步已开启”表示 Deskflow 已启用文字、HTML 和图片剪贴板同步：

- Windows 复制，Mac 粘贴：`Command + V`
- Mac 复制，Windows 粘贴：`Ctrl + V`

如果 Deskflow 自动剪贴板暂时不可用，可使用内置的手动桥接：

1. 在 Windows 控制台点击 **打开文件与剪贴板页**；
2. 在 Mac 浏览器打开同一地址；
3. 在“文字剪贴板”区域点击 **取 Windows 剪贴板**，或把文字粘贴到文本框后点击 **发送到 Windows 剪贴板**。

注意：

- 内置桥接只处理纯文字；
- HTML / 富文本和图片仍依赖 Deskflow 自动剪贴板；
- 文件请使用上面的文件传输功能，不是把文件放进文字剪贴板。

## 7. 高级设置

只有排查问题时才需要进入，包含：

- 共享显示器扫描和输入映射；
- 自动切换和边缘切换；
- 10 秒测试切换；
- 剪贴板测试；
- 浏览器文字桥接入口；
- Deskflow 日志和诊断信息；
- 开机启动。

当前配置为 `autoSwitch=False`、`edgeSwitch=False`，即固定手动切换。不要打开自动切换，除非确实希望鼠标边缘触发显示器换源。

## 8. 关闭和退出

窗口右上角关闭按钮会把控制台最小化到系统托盘，程序继续提供键鼠状态、显示器切换和文件传输服务。
要完全退出，右键托盘图标，选择“退出”。

## 9. 常见问题

### 按钮切换失败

1. 确认“共享显示器”选中的是同时连接两台电脑的那台屏幕；
2. 在显示器 OSD 中开启 DDC/CI；
3. 进入高级设置，点击“测试此显示器（10 秒后恢复）”；
4. 某些显示器在未选中输入时不响应 DDC/CI，此时可在显示器按钮上手动换源。

### Mac 打不开传输地址

按顺序检查：

1. Windows 控制台第 3 区是否显示“传输服务已开启”；
2. Mac 和 Windows 是否连接同一个局域网；
3. 是否完整复制了包含随机令牌的地址；
4. Windows 防火墙是否允许本程序访问“专用网络”；
5. Windows 当前网络是否被识别为“公用网络”，可改为“专用网络”后再试；
6. 如果电脑有多个网卡，控制台可能选择了另一个网卡的 IP，可在高级设置查看诊断信息中的局域网地址。

### 能控制 Mac，但 Deskflow 剪贴板不能粘贴

检查 Windows 的 `Deskflow.conf` 中是否有：

```ini
[server]
enableClipboard=true
```

当前 Windows 已开启此项。若仍不可用，重启 Deskflow 后再试，或使用内置的文字剪贴板桥接。
